# Merchant integration guide

Use the [Payment contract reference](../core/contracts/payment/README.md)
for creation, settlement, recurring payments and refunds. Reconcile a
successful settlement transaction and its token transfers before fulfilling
an order.

Review the [privacy and compliance guide](PRIVACY_AND_COMPLIANCE.md) before
building checkout metadata, structured memos, private invoice routes or audit
exports. For accepted assets and base-unit amounts, see the
[multi-asset and oracle guide](MULTI_ASSET_AND_ORACLES.md). For network and
contract setup, see [Deployment](DEPLOYMENT.md).
